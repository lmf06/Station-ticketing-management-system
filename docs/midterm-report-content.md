# 中期报告填写内容

| 序号 | 项目 | 具体内容 |
| --- | --- | --- |
| 1 | 选题 | 汽车客运站售票管理系统 |
| 2 | 需求分析 | 系统面向旅客、售票员、管理员三类用户。旅客可查询班次、预售购票、查看车票、退票、换票；售票员可办理窗口售票和票务处理；管理员可维护站点、线路、车辆、班次、节假日票价规则和用户信息。 |
| 3 | 系统功能设计 | 前端包括登录注册、旅客购票、窗口业务、系统管理四类界面；后端提供认证、班次查询、订单、车票、后台 CRUD 和销售统计接口。 |
| 4 | 数据库分析与建模 | 初步确定用户、旅客档案、站点、线路、经停点、车辆、座位、班次、票价规则、订单、车票、票务操作记录等实体，并建立实体间联系。 |
| 5 | 数据库设计 | 采用 MySQL 8.x，核心表使用 InnoDB，设置外键、检查约束和索引；票务操作通过事务保证购票、退票、换票的一致性。 |
| 6 | 数据库平台 | MySQL 8.x |
| 7 | 是否进行应用程序开发 | 是，已规划并实现前后端分离 Web 应用。 |
| 8 | 开发工具 | Python Flask、Vue 3、Vite、Element Plus、Flask-SQLAlchemy、PyMySQL、pytest、MySQL Workbench 或命令行。 |
| 9 | 是否支持网络或移动应用 | 支持本地 Web 访问，前端通过浏览器使用；暂不单独开发移动端 App。 |
| 10 | 整体完成进度 | 已完成总体架构、数据库模型、核心 API、前端主要页面、MySQL 脚本和测试验证，后续可补充界面截图和报告排版。 |
