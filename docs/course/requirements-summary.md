## 关键要求
- 独立完成一个数据库应用系统，累计 20 学时。
- 后台数据库可使用 SQL Server 或 MySQL；本项目选择 MySQL。
- 需要完成需求分析、数据分析与建模、数据库设计、应用程序开发与运行、考核答辩。
- 选题表中“车站售票管理系统”的功能重点为：预售票、退票、换票、节假浮动。
- 设计报告正文应包含需求分析、概念设计、逻辑设计、物理设计、功能模块、用户界面、程序代码设计与分析、调试及运行结果。

## 本项目对应关系
- 需求分析：旅客、售票员、管理员三类用户；围绕班次、车辆、座位、票价规则、订单和车票。
- 数据库设计：`sql/mysql_schema.sql` 建立 12 张核心表，包含外键、检查约束和索引。
- 应用开发：`backend/` 提供 API，`frontend/` 提供界面。
- 运行与调试：pytest 验证票务规则，Vite build 验证前端构建。
